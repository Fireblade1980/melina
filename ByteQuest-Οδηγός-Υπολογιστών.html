Hardware: ό,τι αγγίζεις

Hardware ονομάζουμε τα φυσικά μέρη. Συνεργάζονται σαν ομάδα, αλλά το καθένα έχει διαφορετική δουλειά.

⚙️

CPU — επεξεργαστής

Εκτελεί εντολές και υπολογισμούς. Η συχνότητα λειτουργίας του μετριέται σε GHz, όμως η συνολική ταχύτητα εξαρτάται και από τους πυρήνες, τη σχεδίαση και την εργασία.

Scanner & χειριστήριο

Το λειτουργικό σύστημα είναι ο «μαέστρος»: συντονίζει το hardware, τα αρχεία και τις εφαρμογές και σου δίνει το περιβάλλον που βλέπεις.

Μηχανή αναζήτησης

Υπηρεσία που βρίσκει σελίδες με λέξεις-κλειδιά. Τη χρησιμοποιείς μέσα από έναν browser.

Η συσκευή σου→Wi‑Fi ή καλώδιο→Router→Πάροχος internet→Άλλοι servers

Wi‑Fi

Ασύρματη σύνδεση σε κοντινό router. Δεν σημαίνει πάντα ότι υπάρχει και σύνδεση στο internet.

Mobile data

Σύνδεση μέσω του δικτύου κινητής τηλεφωνίας, συνήθως με όριο δεδομένων.

Ασφαλής πλοήγηση

Μην κοινοποιείς διεύθυνση, σχολείο, κωδικούς ή ιδιωτικές φωτογραφίες. Έλεγχε τον αποστολέα και τη διεύθυνση μιας σελίδας. Αν κάτι σε πιέζει, σε φοβίζει ή σου φαίνεται περίεργο, σταμάτα και μίλησε σε ενήλικο που εμπιστεύεσαι.

Μάθε κάτι παραπάνω: URL, HTTPS και server

URL είναι η διεύθυνση μιας σελίδας. Το HTTPS κρυπτογραφεί τη σύνδεση, αλλά δεν εγγυάται ότι κάθε πληροφορία της σελίδας είναι αληθινή. Server είναι υπολογιστής που προσφέρει δεδομένα ή υπηρεσίες σε άλλους υπολογιστές.

Μικρή δραστηριότηταΒρες στη γραμμή διεύθυνσης του browser το όνομα του site και το λουκετάκι. Μην πατήσεις τίποτα ύποπτο — απλώς παρατήρησε.

Τεχνητή νοημοσύνη

Η ΤΝ είναι τεχνολογία που αναγνωρίζει μοτίβα σε πολλά δεδομένα για να κάνει προβλέψεις ή να δημιουργεί περιεχόμενο. Δεν «σκέφτεται» και δεν γνωρίζει όπως ένας άνθρωπος.

Τι μπορεί να προσφέρει

Βοήθεια σε ιδέες, περίληψη, μετάφραση, εξάσκηση, αναγνώριση εικόνων και επεξήγηση δύσκολων εννοιών.

Τι μπορεί να πάει λάθος

Μπορεί να δώσει πειστικές αλλά λανθασμένες απαντήσεις, να επαναλάβει προκαταλήψεις ή να χρησιμοποιηθεί για εξαπάτηση.

«Παραίσθηση»

Όταν ένα εργαλείο ΤΝ επινοεί μια πληροφορία και την παρουσιάζει σαν αληθινή. Γι’ αυτό ελέγχουμε σημαντικές απαντήσεις σε αξιόπιστες πηγές.

Deepfake

Ψεύτικο ή αλλοιωμένο βίντεο, ήχος ή εικόνα που μοιάζει αληθινό. Δεν πιστεύουμε κάτι μόνο επειδή «το είδαμε σε βίντεο».

Ιδιωτικότητα πρώτα

Μην δίνεις σε εργαλείο ΤΝ πλήρες όνομα, διεύθυνση, σχολείο, κωδικούς, προσωπικές συνομιλίες ή φωτογραφίες χωρίς άδεια γονέα/κηδεμόνα και εκπαιδευτικού. Ό,τι πληκτρολογείς μπορεί να αποθηκευτεί από την υπηρεσία.

07

Κώδικας & προγραμματισμός

Προγραμματισμός είναι η δημιουργία ακριβών οδηγιών για έναν υπολογιστή. Οι γλώσσες προγραμματισμού είναι διαφορετικοί τρόποι να γράφουμε αυτές τις οδηγίες.

Python

Καθαρή σύνταξη, δημοφιλής για μάθηση, δεδομένα, αυτοματισμούς και ΤΝ.

print("Γεια!")

JavaScript

Δίνει αλληλεπίδραση στις ιστοσελίδες και μπορεί να χρησιμοποιηθεί και σε servers.

alert("Γεια!")

Scratch

Οπτική γλώσσα με μπλοκ. Βοηθά να μάθεις ακολουθίες, επαναλήψεις και συνθήκες.

HTML & CSS

Η HTML οργανώνει το περιεχόμενο μιας σελίδας. Η CSS ορίζει την εμφάνισή της. Η HTML δεν είναι γενικής χρήσης γλώσσα προγραμματισμού.

Δοκίμασε HTML

Προεπισκόπηση

Πώς φτιάχνεται ένα web app;

Front end

Αυτό που βλέπεις

Κουμπιά, κείμενα, χρώματα και αλληλεπιδράσεις στον browser. Συνήθως με HTML, CSS και JavaScript.

Back end

Αυτό που δουλεύει πίσω

Ένας server επεξεργάζεται αιτήματα, εφαρμόζει κανόνες και μπορεί να μιλά με βάση δεδομένων.

Network programming — προγραμματισμός δικτύων

Είναι η δημιουργία προγραμμάτων που επικοινωνούν μέσω δικτύου. Παράδειγμα: μια εφαρμογή στέλνει αίτημα «δώσε μου τον καιρό» σε έναν server, και ο server απαντά με δεδομένα. Οι κανόνες αυτής της επικοινωνίας λέγονται πρωτόκολλα.

Client ζητά→Δίκτυο μεταφέρει→Server απαντά
Μάθε κάτι παραπάνω: αλγόριθμος, μεταβλητή, συνθήκη

Αλγόριθμος: βήματα για μια λύση. Μεταβλητή: κουτάκι με όνομα που κρατά τιμή. Συνθήκη: επιλογή τύπου «αν συμβαίνει αυτό, κάνε εκείνο».

08

Ψηφιακές δεξιότητες

Μικρές συνήθειες που σε βοηθούν να δουλεύεις γρήγορα, οργανωμένα και με ασφάλεια.

Αρχεία & φάκελοι

Το αρχείο είναι ένα αποθηκευμένο αντικείμενο. Ο φάκελος οργανώνει αρχεία και άλλους φακέλους. Δώσε σαφή ονόματα: Ιστορία_Εργασία_2026.docx.

Extensions

Η κατάληξη δείχνει συχνά τον τύπο: .docx έγγραφο, .xlsx φύλλο, .pptx παρουσίαση, .jpg εικόνα, .pdf σταθερό έγγραφο.

Save & Save As

Save ενημερώνει το ίδιο αρχείο. Save As φτιάχνει νέο αντίγραφο με άλλο όνομα, μορφή ή θέση.

Copy, cut, paste

Ctrl/⌘ C αντιγραφή · Ctrl/⌘ X αποκοπή · Ctrl/⌘ V επικόλληση · Ctrl/⌘ Z αναίρεση.

Download & upload

Download: αρχείο από internet προς τη συσκευή. Upload: από τη συσκευή προς μια online υπηρεσία.

Screenshot

Φωτογραφία της οθόνης ή μέρους της. Έλεγξε μήπως φαίνονται προσωπικά στοιχεία πριν τη μοιραστείς.

Κωδικοί πρόσβασης

Χρησιμοποίησε μακρύ, μοναδικό κωδικό για κάθε υπηρεσία και, όπου γίνεται, επαλήθευση δύο βημάτων. Δεν τον μοιράζεσαι με φίλους.

Backup & cloud

Backup είναι δεύτερο αντίγραφο για ώρα ανάγκης. Cloud είναι αποθήκευση σε απομακρυσμένους servers — όχι «μαγικό σύννεφο».

Updates

Οι ενημερώσεις διορθώνουν προβλήματα, κλείνουν κενά ασφαλείας και προσθέτουν βελτιώσεις. Εγκατάστησέ τες με άδεια ενήλικα όπου χρειάζεται.

Απλό troubleshooting

1. Διάβασε το μήνυμα. 2. Έλεγξε ρεύμα/σύνδεση. 3. Κλείσε και άνοιξε την εφαρμογή. 4. Κάνε ασφαλή επανεκκίνηση. 5. Ζήτησε βοήθεια.

Αποστολή οργάνωσης
  1. Φτιάξε φάκελο «ByteQuest».
  2. Μέσα, φτιάξε υποφακέλους «Κείμενα» και «Εικόνες».
  3. Αποθήκευσε ένα αρχείο με καθαρό όνομα.
  4. Κάνε ένα αντίγραφο με Save As.
Μάθε κάτι παραπάνω: δεδομένα και δυαδικό σύστημα

Οι υπολογιστές αναπαριστούν κείμενο, εικόνα και ήχο ως δεδομένα. Στο πιο βασικό επίπεδο χρησιμοποιούν δύο καταστάσεις, 0 και 1. Για παράδειγμα, ο αριθμός 5 γράφεται 101 στο δυαδικό σύστημα.

CheckpointΘέλεις να κρατήσεις το αρχικό και να φτιάξεις διαφορετική έκδοση. Τι επιλέγεις;

Τελική αποστολή

20 ερωτήσεις για να δεις τι θυμάσαι. Μπορείς να προσπαθήσεις ξανά όσες φορές θέλεις.

Τρεις δημιουργικές ασκήσεις
  1. Σχεδίασε σε χαρτί τη διαδρομή ενός μηνύματος από το κινητό σου μέχρι έναν φίλο.
  2. Γράψε αλγόριθμο 6 βημάτων για να φτιάξεις ένα τοστ. Ζήτησε από κάποιον να τον ακολουθήσει ακριβώς.
  3. Φτιάξε παρουσίαση 3 διαφανειών: hardware, internet, ασφάλεια. Βάλε έως 3 βασικές ιδέες σε κάθε διαφάνεια.
